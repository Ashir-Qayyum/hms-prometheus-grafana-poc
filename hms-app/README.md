# Hospital Management System

A full-stack Hospital Management System built using Java Spring Boot Microservices and React.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Cloud Gateway
- Eureka Server
- Spring Data JPA
- MySQL
- Maven

### Frontend
- React
- Vite
- Mantine UI
- Axios
- React Router

## Microservices

- Eureka Server
- API Gateway
- User Service
- Profile Service
- Appointment Service
- Pharmacy Service
- Media Service
